# docs/archive/

Исторические документы, перемещённые из корня `docs/` в рамках Sprint 3.41 (doc-archive) для снижения cognitive load при навигации.

## Структура

- `2026-08/` — 140 отчётов за август 2026 (Sprint 1-17, MVP completion rounds,
  AI-TUTOR-AUTONOMOUS-*, AI-TUTOR-EVIDENCE-*, status snapshot'ы, evidence).

## Не трогать

- Это **read-only archive** для исторической справки.
- Новые документы класть в корень `docs/` или другие подпапки.
- Если нужно обновить содержимое — лучше создать новый файл в корне,
  чем править архивный (иначе теряется смысл архива).

## Доступ

- Все 140 файлов доступны по прежним относительным путям
  (`git log --follow <file>` покажет историю).
- Поиск: `grep -r "<term>" docs/archive/2026-08/`.
