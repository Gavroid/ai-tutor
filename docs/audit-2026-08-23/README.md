## TL;DR (для владельца)

**Текущий статус: `internal MVP / broken failsafe — Кириллу можно давать только math-6 после 2-3 дней hotfix.**

**Главный блокер (P0):** fail-closed evidence-store сломан на проде — API говорит `mvp_ready=True` для 16/16 предметов, в `evidence.json` `promotion_allowed=true AND blocked_reason=blocked_ocr` одновременно, UI показывает «MVP-ready» даже там, где `practice=0/10`. Ребёнок не сможет отличить готовый предмет от пустого.

**Что есть хорошего:** стабильный backend-стек (637 + 135 = 772 теста зелёных), рабочий AI explain с markdown-рендерингом, родительский дашборд со SM-2, JWT-cookie + rate-limit, RAG с embeddings, читаемый Prism-UI без белых панелей, реальные школьные планы на 16 предметов.

**Главная цель:** 2 спринта hotfix (P0) + 4 спринта контента/UX (P1) + 2 спринта hardening (P2) → передать Кириллу + родителю на постоянное использование.
